## 3.2 (2026-09-24)

First public release.

- Tasks from GitHub Projects across one or more orgs, grouped by status and board
- Issues from repos without a board, and repos added on their own
- Pull requests that need you, with check status
- Standup for any date range, copied with formatting
- Notes, project links, world clocks, tech news and trending
- Sign in with GitHub (device flow), or a personal access token; several accounts
- Brutal, Clay and Soft looks, light and dark
- Fun extras: contribution streak, achievements, week in code, easter eggs
- Fast loading: saved data first, then boards, then the rest; offline badge and auto-refresh
- Switch new tabs between Tabboard and Chrome's own page
