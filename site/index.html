Setup

Up and running in a minute.

Tabboard isn't on the Chrome Web Store yet, so for now it installs from GitHub.

Get the code

Clone the repo, or download the ZIP from GitHub and unzip it.

git clone https://github.com/mifraheem/tabboard

Load it in Chrome

Open chrome://extensions, turn on Developer mode, then Load unpacked and pick the folder.

Sign in with GitHub

Open a new tab, enter the short code on github.com and pick your orgs. That's it.
