Set up in a minute

Three steps. No account.

Tabboard isn't on the Chrome Web Store yet. Until then, it installs from GitHub.

1

Get the code

Clone the repo, or download the ZIP from GitHub and unzip it.

git clone https://github.com/mifraheem/tabboard
2

Load it in Chrome

Open chrome://extensions, turn on Developer mode, click Load unpacked and pick the folder.

3

Sign in with GitHub

Open a new tab, enter the short code on github.com, pick your orgs. Done.

Private by design

Your work stays yours.

There's no Tabboard server. Your browser talks to GitHub directly, and nothing about you or your work is collected.

Read the privacy policy
