Privacy policy

Last updated 24 September 2026

Tabboard is a Chrome extension that shows your GitHub work on the new tab page. It has no server of its own, and the people who make it can't see your data.

What Tabboard collects

Nothing. There are no analytics, no tracking and no ads, and no data is sold or shared.

What it stores, and where

Everything is kept in the extension's storage in your own browser, and nowhere else:

  • Your GitHub sign-in token, so it can load your data
  • A copy of your last loaded boards and pull requests, so new tabs open instantly
  • Your notes, project links, clocks and settings

This storage isn't encrypted. Anyone with access to your computer account could read it, like other browser data. Signing out removes the token.

Who it talks to

ServiceWhy
api.github.comYour boards, issues, pull requests and contribution calendar, using your token
github.com/loginSigning in with GitHub
hn.algolia.com, simonwillison.net, huggingface.coTech news, only for the sources you turn on. No personal data is sent.

Your GitHub data goes directly between your browser and GitHub. GitHub's own privacy statement covers what GitHub does with it.

Permissions

Storage remembers whether new tabs open Tabboard or Chrome's page. Active tab lets the toolbar icon switch the tab you're on. Tabboard doesn't read your browsing history or the pages you visit.

Removing your data

Sign out from the avatar menu, or remove the extension to delete everything it stored. To revoke GitHub access, go to GitHub → Settings → Applications and revoke Tabboard.

Contact

Questions go to GitHub issues. Please report security problems privately, as described in the security policy.
